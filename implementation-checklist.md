## 🚨 RED FLAGS & ESCALATION

### Ad Performance Red Flags
```
❌ CTR < 2.5% → Pause creative (low engagement)
❌ CPC > €2 → Audience too broad, reduce
❌ CPM > €6 → Frequency fatigue, rotate creative
❌ Conversion rate < 5% → Landing page issue, debug
```

### Email Performance Red Flags
```
❌ Open rate < 20% → Subject line issue, A/B test
❌ Click rate < 3% → CTA weak, revise copy
❌ Bounce rate > 5% → List quality issue, check segments
❌ Unsubscribe rate > 0.5% → Content not matching expectation
```

### Landing Page Red Flags
```
❌ Bounce rate > 50% → Hero section problem, redesign
❌ Time on page < 1 min → Not engaging, audit copy
❌ Conversion rate < 8% → Form friction, simplify
❌ Mobile CTR < 60% of desktop → Mobile UX broken
```

### Escalation Protocol
```
If ANY red flag appears:
1. Investigate root cause (same day)
2. Implement quick fix (24-48h)
3. A/B test solution (72h)
4. Scale if working (1 week)
5. Document learnings
```
