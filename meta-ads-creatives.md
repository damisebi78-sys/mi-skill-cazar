## 🔄 A/B TESTING PLAN

### Phase 1: Creative Testing (Week 1-2)
```
Test 1: Variante 1 vs Variante 2
Budget: 50/50
Winner: >20% mejor CTR

Test 2: Copy Variations (dentro del ganador)
Budget: Versión A vs B vs C (33/33/33)
Winner: Mejor CTR + relevancia

Test 3: Image/Video variations
Budget: Foto real vs video vs animación (33/33/33)
Winner: Mejor engagement
```

### Phase 2: Audience Testing (Week 2-3)
```
Test 1: Segment A vs B vs C
Budget: 40/35/25 (proporcional)
Winner: Mejor ROAS en el funnel

Test 2: Bid Strategy
Budget: CPC vs ROAS vs Conversions (33/33/33)
Winner: Más eficiente según objetivo
```

### Phase 3: Scaling (Week 3+)
```
- Scale winner creative x2-3 budget
- Keep A/B test running (5% budget)
- Monthly creative refresh (new angle)
- Audience expansion based on winners
```
