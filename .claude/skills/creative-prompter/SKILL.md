# Creative Prompter: Guía de Prompts Visuales

Especialidad: Redacción de prompts fotográficos y de video cinemáticos con especificaciones técnicas que producen creativos publicitarios de nivel editorial.

## Anatomía de un Prompt Profesional

### Estructura Base
```
[SCENE SETUP] → [SUBJECT] → [ACTION/MOOD] → [LIGHTING] → [CAMERA SPECS] → [STYLE/GRADE]
```

### Ejemplo Completo
```
PHOTOGRAPHIC BRIEF FOR META ADS (Tejido/Crochet)

📷 SCENE:
Clean white background with soft shadow, studio setting

👤 SUBJECT:
Woman (30s, Latina, warm smile) holding large crocheted blanket, 
displaying intricate texture detail

🎬 ACTION/MOOD:
She's proudly showing her handmade creation, genuine joy, 
connection with product, hands visible

💡 LIGHTING:
Soft window light (north-facing simulation), 
3-point key-fill-back setup, 
no hard shadows on face, 
warm color temperature (5500K)

📹 CAMERA:
Canon EOS R5 equivalent
Lens: 85mm f/1.4 (portrait compression)
ISO: 200 / f/1.8 aperture / 1/125s shutter
Focus: Sharp on eyes, soft bokeh background (blur ratio 1.5:1)

🎨 STYLE & COLOR GRADE:
Bright, airy, minimal aesthetic
Warm color temperature (+200K)
Slight desaturation of everything except warm tones
Slight lifted blacks (film-like feel)
High key image (approx 70% avg luminance)

COMPOSITION:
Rule of thirds, subject left-third, hands prominent in frame
Negative space: 40% background, 60% subject
Depth: Shallow, bokeh present

OUTPUT: High-res JPG 1080x1350px (Instagram story ratio)
```

## Parámetros Técnicos Explicados

### 📷 CÁMARA RECOMENDADA (por generador AI)

**Para Fotos Fijas:**
- Canon EOS R5 / Sony A7R V (equivalente)
- Canon 5D Mark IV / Nikon Z9

**Lentes Recomendados:**
```
📸 Retrato: 85mm f/1.4 (compresión, bokeh)
📸 Producto: 50mm f/1.8 (neutral, versátil)
📸 Ambiental: 35mm f/1.4 (contexto + closeup)
📸 Overhead: 24mm f/2.8 (flatlay, composición)
```

### 💡 ILUMINACIÓN (Tres Tipos Clave)

**1. Soft Key Light (Principal)**
- Fuente: Ventana / Softbox grande / Reflector
- Ángulo: 45° desde arriba
- Intensidad: Primaria
- Crear: Dimensión facial sin sombras duras

**2. Fill Light (Relleno)**
- Fuente: Reflector blanco / Panel difusor
- Ángulo: Opuesto a key (45° otro lado)
- Intensidad: 50-70% del key
- Función: Ablandar sombras

**3. Back Light (Contraluz)**
- Fuente: Luz separada / Ventana atrás
- Ángulo: Atrás + arriba
- Intensidad: 60-80% del key
- Función: Separar sujeto del fondo

**Color Temperature:**
- Daylight: 5500K-6500K (natural)
- Tungsten: 3200K (cálido, nostálgico)
- Mixed: 4500-5000K (neutral, moderno)

### 🎬 APERTURA & PROFUNDIDAD DE CAMPO

```
f/1.2-1.4  → Bokeh extremo (detrás difuso)     | Retrato premium
f/1.8-2.8  → Bokeh natural (buen balance)      | Retrato estándar
f/4.0-5.6  → Profundidad media (contexto)      | Lifestyle/producto
f/8.0+     → Profundidad total (fondo nítido)  | Ambiental/grupo
```

### 🎨 COLOR GRADING PARA LATAM

**Warm + Aspirational** (Más vendible)
- Saturation: +15-20%
- Température: +200K (más cálido)
- Lift blacks: +10-15 (brillante)
- Contrast: +5 (pop)

**Cool + Professional** (Confianza)
- Saturation: -5-10%
- Temperature: -100K (más frío)
- Lift blacks: Normal (20)
- Contrast: +10 (definición)

**Vintage/Nostalgic** (Autenticidad)
- Saturation: -20-30%
- Fade blacks: +20-25
- Vignette: -15 (edges oscuros)
- Grain: +5-10% (film feel)

### Prompt 1: "La Orgullo de la Creadora" (Retrato Principal)

```
PHOTO BRIEF - HIGH PRIORITY

Scene: Bright, minimalist home studio with white seamless backdrop
Lighting: 3-point (key north window simulation, fill reflector, back separation light)
Subject: Latina woman (28-35 years old, genuine warm expression) holding completed crochet blanket
Action: She's gently displaying the texture of her handmade blanket, hands prominently framing the work
Mood: Pride, accomplishment, professional artisan energy

Camera Specs:
- Camera Type: Canon EOS R5 / Sony A7RV
- Lens: 85mm f/1.4
- Settings: ISO 200, f/1.8, 1/125s
- Focus: On subject's eyes, hands sharp, background bokeh
- Composition: Rule of thirds (subject left), 40% background negative space
- Depth: Shallow focus with smooth bokeh

Lighting Details:
- Key Light: Soft window light, 45° camera-left, 5500K
- Fill: White reflector 45° camera-right, 60% intensity
- Back: Subtle rim light from behind to separate from background
- No hard shadows, overall high-key (luminance ~68%)

Color Grading:
- Temperature: +250K (warm, inviting)
- Saturation: +18% (rich, vibrant)
- Lift blacks: +12% (airy, clean)
- Contrast: +8 (definition)
- Slight film grain: +3% (authentic)
- Vignette: -8 (subtle edges)

Output Format: 1080x1350px (Instagram Story optimal), JPG HQ
Style: Commercial editorial / lifestyle brand photography
Comparable Aesthetic: Etsy brand photography, Handmade Goods aesthetic
```

### Prompt 2: "El Proceso de Creación" (Video/Carousel)

```
VIDEO PROMPT - 15-30 SEC LOOP

Scene Sequence:
1. Close-up hands weaving (crochet hook detail)
2. Pan to completed pattern/section
3. Wide shot: Creator focused, workspace organized
4. Final: Finished product with hands

Lighting: Warm key light + natural ambient, consistent throughout
Camera Movement: Slow parallax shifts, NO jarring cuts
Audio Cue: Soft, rhythmic (crochet sounds or lo-fi music)

Camera Specs:
- Camera: Sony FX30 / Canon R5 + 4K codec
- Lens: 35mm f/1.4 (lifestyle view) + 85mm f/1.8 (close detail)
- Frame Rate: 24fps (cinematic)
- Resolution: 4K (downscale to 1080p for ads)
- Shutter: 1/48s (motion blur natural)

Lighting:
- Key: Warm window light (3200-4000K, soft)
- Fill: Minimal (let shadows tell story)
- Back: Subtle rimlight on hands
- Workspace lamp (practical light, on-screen)

Color Grade:
- LUT: "Warm Indie" or "Creamy Vintage"
- Saturation: +12%
- Shadows: Warm cast (-15% blues, +10% yellows)
- Highlights: Lifted, clean
- Grain: +2% (35mm film feel)

Composition:
- 90% hands/product detail
- 10% creator face (emotion)
- Negative space: Minimal (busy, satisfying)
- Aspect Ratio: 9:16 (Vertical video - mobile first)

Output: MP4 H.264, 1080x1920px, 30fps, 15-30sec loop, <50MB
Mood: Meditative, satisfying, authentic, ASMR-adjacent
```

## Componentes Reutilizables (Copy-Paste Ready)

### Lighting Template Standard
```
LIGHTING SETUP - REUSABLE:
- Key Light: North-facing window (soft diffuse), 5500K, 45° camera-left
- Fill Light: White reflector, 60% intensity, 45° camera-right
- Back Light: Subtle separation (rim), 70% of key intensity, behind subject
- Result: High-key, no harsh shadows, warm dimensional feel
```

### Camera Defaults for Ads
```
CAMERA DEFAULTS (unless specified):
- Focal Length: 50mm (neutral) or 85mm (portrait)
- Aperture: f/1.8-2.8 (shallow depth, bokeh)
- Shutter: 1/125s (handheld safe)
- ISO: 200-400 (noise-free)
- White Balance: 5500K (daylight)
- Focus: On eyes / product hero element
```

## Checklist de Prompt Profesional

- [ ] **Scene Setup**: Específico y visual (no abstracto)
- [ ] **Subject**: Descripción detallada (edad, etnia, pose, expresión)
- [ ] **Lighting**: 3-point setup especificado (key/fill/back)
- [ ] **Camera Specs**: Lente, apertura, ISO, shutter, ratio
- [ ] **Color Temperature**: En Kelvin (3200K-6500K)
- [ ] **Color Grading**: Cambios específicos (saturation, lift, contrast)
- [ ] **Composition**: Rule of thirds, negative space, profundidad
- [ ] **Output Format**: Resolución, relación de aspecto, codec
- [ ] **Mood/Style**: Comparable a brand/aesthetic conocida
- [ ] **Restricciones**: NO harsh shadows / NO oversaturated / etc.
