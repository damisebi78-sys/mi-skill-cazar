# Copywriting de Ventas para Infoproductos

Especialidad: Redacción de páginas de venta, creativos publicitarios y secuencias de email orientadas a conversión máxima para productos digitales en mercados LATAM (español).

## Principios Clave

### Estructura de Página de Venta (VSL Format)
1. **Headline Hook** (3-5 segundos): Beneficio claro + curiosidad + problema resuelto
   - Ej: "Cómo generar 47 diseños de tejido en PDF sin saber programación (ni tener experiencia)"
2. **Problema + Frustración** (empatía): Reconocer el dolor específico
3. **Agitación** (amplificar): Mostrar consecuencias de NO actuar
4. **Solución** (introducir): Cómo tu producto resuelve ESPECÍFICAMENTE
5. **Prueba Social** (confianza): Testimonios, números, garantías
6. **Call-to-Action** (urgencia): Oferta limitada, bonificación, tiempo

### Principios LATAM Específicos
- **Tono conversacional** (no corporativo): "vos" / "tú" según país
- **Coloquialismo local**: Expresiones naturales del país (AR, MX, CO, etc.)
- **Social proof auténtico**: Nombres reales + testimonios específicos, no genéricos
- **Precio psicológico**: $47 > $50 (terminaciones en 7 o 9)
- **Urgencia real**: Bonificaciones con fecha de cierre, no promesas falsas
- **Beneficios emocionales**: Libertad, reconocimiento, confianza en sí mismo

## Checklist de Copywriting

- [ ] **Headline**: Claro, beneficio + curiosidad
- [ ] **Empatía**: Reconoce el problema específico del avatar
- [ ] **Agitación**: Muestra el costo de NO actuar
- [ ] **Solución**: Presenta el producto como la respuesta
- [ ] **Proof**: Mínimo 1 testimonio específico + números
- [ ] **CTA**: Claro, accionable, con urgencia real (no fake)
- [ ] **Tono**: Conversacional, local, auténtico
- [ ] **Precio**: Psicológico (termina en 7 o 9)
- [ ] **Garantía**: 30 días devolución si no satisface
