## Principios de Diseño

### Color Palette (Conversión LATAM)
- **Primary CTA**: Verde intenso o Rojo vibrante (#10B981 o #EF4444)
- **Secondary**: Azul confianza (#3B82F6)
- **Accent**: Oro/naranja (urgencia) (#F59E0B)
- **Background**: Blanco limpio o gris muy claro (#F9FAFB)
- **Text**: Negro/gris oscuro (#1F2937)

### Tipografía
- **Headlines**: Sans-serif bold (Poppins, Inter, Montserrat) - 32px-48px
- **Body**: Sans-serif regular (Inter, Open Sans) - 16px
- **CTA**: Sans-serif bold, ALL CAPS - 16px-18px

### Espaciado
- Márgenes generosos (40px-60px top/bottom entre secciones)
- Padding interno en cajas: 24px-32px
- Ancho máximo: 900px (para legibilidad)

### Elementos Interactivos
- **CTA Buttons**: 
  - Mínimo 48px altura
  - Padding: 14px 32px
  - Hover: Escala 1.05 + sombra
  - Animation: 0.3s ease-in-out
  
- **Scroll Reveal**: 
  - Elementos aparecen al scroll (parallax suave)
  - Fade-in + slide-up (200-400ms)

## Componentes Clave

### Hero Section
- Headline + Subheadline + CTA
- Imagen heroica (16:9 o 4:3)
- Background: Gradient sutil o color sólido
- Sin demasiadas palabras (máx 50)

### Trust Badges
```
✅ [Número de clientes felices]
✅ [Años en el negocio]
✅ [Garantía dinero-atrás]
⭐ [Rating promedio]
```

### Scarcity Elements
- Contador de stock (si aplica)
- Contador de tiempo (oferta limitada)
- "Solo [N] espacios disponibles"
- Honestidad: NO inventar urgencia falsa

## Checklist de Landing

- [ ] **Headline**: Beneficio claro, sin jerga
- [ ] **Hero Image**: Visual que representa solución
- [ ] **CTA Above Fold**: Visible sin scroll
- [ ] **Problema → Solución**: Flujo narrativo claro
- [ ] **Testimonios**: Mínimo 2-3 con foto + nombre + país
- [ ] **Trust Signals**: Garantía + seguridad de pago
- [ ] **Mobile Responsive**: Se ve bien en 320px-1920px
- [ ] **Loading Speed**: < 2 segundos
- [ ] **Colores**: Contraste WCAG AA mínimo
- [ ] **Footer**: Links + info legal + soporte
